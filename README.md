# fluida

ゆらして描く、えのぐあそび（フルイドアート）のウェブアプリ。
えのぐを落として、ながして、世界にひとつの模様をつくる。

Navier-Stokes 流体シミュレーション（Stable Fluids）を WebGL2 で実装しており、
なぞった軌跡は途切れず流れ、色は混ざり合い、ひと滴ごとに表情が変わる。

## 使い方

- **しずく** — タップでひと滴。おしたまま動かすと連なる
- **ながし** — なぞった場所の絵の具が流れる
- **くし** — 画面ぜんたいに櫛目がはしる
- **うず** — まるく回すと渦がまきおこる
- **おまかせで描く** — パターンをランダム生成。インクが咲いていくのを眺めてから、自分でゆらして仕上げる

えのぐばこはアクリルポーリングの定番配色からキュレーションした 8 種
（うみ・もり・つきよ・ゆうやけ・そら・さくら・すみれ・つち）+ 自由に色を決められる「じぶんいろ」。
どの色を選んでも調和するので、配色に迷わない。

仕上がりは 2048×2048 の PNG として保存できる。

## 開発

```sh
pnpm install
pnpm dev        # 開発サーバー
pnpm test       # ユニットテスト (vitest)
pnpm typecheck  # 型チェック
pnpm check      # lint + format (vp check)
pnpm build      # プロダクションビルド
```

ツールチェーンは [vite-plus](https://voidzero.dev) (`vp`) + pnpm。
UI は [@k8o/arte-odyssey](https://github.com/k35o/arte-odyssey) を使用。
WebGL2（`EXT_color_buffer_float`）が必要。
